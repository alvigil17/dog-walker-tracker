# Dog Walking Tracker

This project is a simple dog walking tracker.

The page lets a user add a dog walk and keep track of the dog name date walk time and notes.

## Features

Add a dog walk

Show walks on the page

Check for blank form boxes

Load example walks from a JSON file

Clear all walks with a button

## Tools Used

HTML

CSS

JavaScript

Bootstrap

jQuery

JSON

Git

Vercel

## How to Run

Open the project with Live Server in Visual Studio Code.

The page will load example walks from the JSON file.

You can also add your own walks using the form.
